# Tracker Treningów

Aplikacja desktopowa do zapisywania treningów i liczenia czasu aktywności
w miesiącu. Powstała podczas praktyk zawodowych.

## Co potrafi

- dodawanie, edycja i usuwanie treningów
- filtrowanie po miesiącu, wyszukiwanie po rodzaju i notatce
- oznaczanie ważnych treningów
- podsumowanie: suma minut i liczba treningów
- eksport raportu do TXT i CSV
- dane zapisywane automatycznie w pliku JSON

## Technologie

C# / .NET 10 / Windows Forms

## Jak uruchomić

1. Otwórz `TrackerTreningow.sln` w Visual Studio 2022.
2. Naciśnij F5.

Dane są zapisywane w `%LocalAppData%\TrackerTreningow\trainings.json`.
